KNX-DALI Gateway USB Web Flasher

Flashes both ESP32-C6 application firmware and LittleFS Web UI in one click

KNX⇄DALI
Safety First: Disconnect KNX bus, DALI bus, and 24 V auxiliary power terminals before connecting USB-C for initial flashing.
1. Browser: Open this page in Google Chrome or Microsoft Edge (WebSerial required).
2. Connect: Plug the Seeed XIAO ESP32-C6 into your computer via USB-C.
3. Flash: Click Connect & Install below to flash bootloader.bin, partitions.bin, firmware.bin, and littlefs.bin.
4. Subsequent Updates: Once flashed, future updates can be dragged and dropped wirelessly in the gateway's Firmware Web UI tab.
Your browser does not support WebSerial. Please open this page in Google Chrome or Microsoft Edge. WebSerial requires HTTPS or localhost.
