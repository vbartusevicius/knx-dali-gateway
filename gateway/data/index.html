DALI Commissioning & Maintenance

ETS owns the authoritative KNX association & group configuration. Commissioning commands below run through the same serialized DALI worker queue as ETS function properties.

Scan DALI Control Gear (0..63)

Queries presence, status byte, and DT8 colour capabilities on all 64 short addresses.

Address Unaddressed DALI Gear

Runs IEC 62386-102 random-address binary search for new ballasts without changing existing addresses.

Replace Single Ballast

Assigns one unaddressed replacement ballast to an absent short address and restores its groups & level.

Scan & Address DALI-2 Input Devices (Part 103)

Inventories 24-bit multi-master sensors/buttons (301/303/304) and configures instance event filters.

Synchronize Gateway Wall-Clock Time

Syncs browser UTC epoch to the gateway so persistent error logs and DALI debug traces record exact wall-clock timestamps.
