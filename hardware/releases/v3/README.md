# KNX-DALI gateway hardware v3 (1 DIN, two boards)

**Revision D (2026-10-22).** Changes against rev C (`59eea1f`, the first order): AUX-powered core (TRACO TMR 1-2411 U9 isolated converter, hand-fitted, plus TI TPS2121 U10 priority mux with the KNX buck as fallback); XIAO LM66100 U7 CE on VOUT (no USB back-feed); DALI TX clamp 2R, gate divider 4k7/10k, RX pull-up 4k7, buck EN 100k; enclosure with channels over the back-side diodes, board edge reliefs, backing ribs, C-shaped spring button tabs with front bumps and plungers, OLED supports beside the panel, longer DALI terminal slot; through-hole leads trimmed to 1.5 mm; a base right-wall recess over U9. Rev C boards and prints: follow [`hardware/docs/rework-rev-c.md`](../../docs/rework-rev-c.md) (pins in `rework/`). NCN5130 cluster re-placed to the datasheet layout rules (C1/C2/C3/C5/C15, L1).

Generated by `HARDWARE_VARIANT=v3 python3 hardware/scripts/release.py v3` from
`hardware/layout/v3/`, with the same gates as v2: KiCad DRC 0 errors and 0
unrouted, every part orderable or hand-fit, every JLC part checked against
JLCPCB's part record, live stock and its EasyEDA footprint (pin for pin; the
placement file carries the fitted rotations and centres). CI
(`HARDWARE_VARIANT=v3`, `test_release_current.py`) fails as soon as either board
no longer matches this release.

## Ordering at JLCPCB

1. **Recommended — Order as 1 Breakaway Panel (`panel/`):**
   - Upload `panel/panel_gerbers.zip` and select **4 layers, `1.2 mm` PCB Thickness** on JLCPCB's order page (note: JLCPCB's web form always defaults the thickness radio button to `1.6 mm` until you click **`1.2`**).
   - Enable **PCB Assembly (Both Sides)** and upload `panel/panel_bom_jlc.csv` + `panel/panel_cpl_jlc.csv`.
2. **Or Order as Separate Boards (`main/` and `ui/`):**
   - Upload `main/main_gerbers.zip` and `ui/ui_gerbers.zip` (4 layers, **1.2 mm**).
   - Upload `<board>_bom_jlc.csv` + `<board>_cpl_jlc.csv`.
3. `<board>_assembly_check.csv` (and `panel/panel_assembly_check.csv`) lists JLCPCB footprint, rotation and stock for
   every part.


## Ordering elsewhere (Aisler, PCBWay, Eurocircuits, ...)

Each board folder and `panel/` also holds fab-independent files:

- `<board>_odb.zip`: ODB++ (copper, drills, outline, netlist, component
  placement). Aisler's preferred upload; PCBWay and Eurocircuits accept it.
- `<board>_gerbers.zip`: Gerber X2 per layer, Excellon drills (plated and
  non-plated) and `<board>.d356`, the IPC-D-356 netlist for the electrical test.
- `<board>_bom.csv`: every part with value, footprint, manufacturer part number
  (LCSC number for reference), SMD/THT, and whether the assembler or you fit it.
- `<board>_cpl.csv`: placement of the assembled parts in KiCad's coordinates
  and rotations (the `_jlc` files use JLCPCB's rotations and are for JLCPCB only).

Order the stack-up, thickness and finish given above; check the assembler's
placement preview for the bottom-side and rotated parts as for JLCPCB.

## Hand-fitted parts (`<board>_hand_fit.csv`)

- `main` J1, J2: two **Phoenix Contact 1574200** (PST 1,0/2-5,75) pin strips on
  the bottom shoulder of `main` (pins pointing +x to the right), mated from the
  right side through crafted pockets with 30-deg half-butterfly dovetail keyways
  by the red/black KNX plug (`1574300`, bottom-front, flush with y=0) and the
  yellow/grey 20-32 V AUX plug (`1574299`, bottom-rear, flush with y=0).
  (`main` J3, the DALI push-in spring terminal `KF142R-5.08-2P`, LCSC `C475144`,
  is JLC-assembled on the top shoulder of `main`.)
- `main` U3: RECOM **REC3-2415SRW/H2/A/CTRL** (or **REC3-2415SRW/H4/A/M/CTRL**, DIP-24, A pinning with pin 1 CTRL; clip unused pins 3 and 11 flush before soldering; or Mean Well **SCWN06B-15** / **SCW03B-15** if software PSU shut-off is not needed).
- `main` U8: Seeed **XIAO ESP32C6 Pre-Soldered (SKU 102010636)** in two 1x7
  5.0 mm female headers (`assembly_parts.csv`).

Off-board parts (including the **0.96" 64x128 SSD1312** 14-pin `0.62 mm`-pitch
OLED `QG-6428TSWCG02` / `NFP1312-15AY`, whose `12.0 mm` flex tail folds through
the `9.8 mm` top notch on `ui` and solders onto `ui` J2) are in `assembly_parts.csv`.
